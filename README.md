# Inventory Vegetable Management System

## Project Overview
The Inventory Vegetable Management System is a console-based Python application designed to manage vegetable stock and sales in a vegetable shop.

The application provides two user roles: Shopkeeper and Customer. Shopkeepers can manage inventory, while customers can purchase available vegetables, add items to their cart, and view their total bill.

## Technologies Used
- Python
- Python Lists
- Conditional Statements
- Loops
- Functions (future enhancement)

## Features

### 1. Shopkeeper Module
- Add new vegetables to inventory.
- Remove vegetables from inventory.
- Update vegetable quantity and price.
- View available inventory.
- View sales reports.

### 2. Customer Module
- View and select available vegetables.
- Enter required vegetable quantities.
- Check product availability and stock.
- Add vegetables to the shopping cart.
- View cart details.
- Generate the final bill.
- Calculate the total purchase amount.

### 3. Inventory Management
- Maintain vegetable names, quantities, and prices using Python lists.
- Automatically update stock after customer purchases.
- Prevent purchases when sufficient stock is unavailable.

### 4. Sales Management
- Track sold vegetable names.
- Maintain sales quantities and amounts.
- Display a sales report for the shopkeeper.

## Concepts Used

- List Methods (`append()`, `remove()`, `pop()`, `index()`)
- Conditional Statements (`if`, `elif`, `else`)
- Loops (`while`, `for`)

## How to Run the Project

1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project folder:
   ```bash
   cd Inventory-Vegetable-Management-System
   ```

3. Run the Python program:
   ```bash
   python main.py
   ```
